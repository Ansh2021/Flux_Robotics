## Games
Features three distinct games:
- FRCdle (FRC Wordle)
  - Guess a randomly generated team just like one has to guess a randomly generated word on Wordle
  - Select a desired region and difficulty to change the pool of possible randomly generated teams
- FRC Trivia
  - Answer questions specific to the _FIRST_ Robotics Competition
  - Select from four categories, three eras, three difficulties, and three answer types to change the questions you receive
- FRC Clicker
  - Like potentially the most popular clicker game of all time, Cookie Clicker, click on the FRC REBUILT fuel to buy upgrades and get more fuel (you can never have too much fuel)
